# Controller branding assets

Default images were requested by the project owner from https://teamsummit.org/ on 2026-10-09:

- `logo.svg`: https://teamsummit.org/wp-content/uploads/2024/05/TEAMSUMMITwebLOGO_white-03.svg
- `hero.jpg`: https://teamsummit.org/wp-content/uploads/yootheme/cache/ff/nor2-ff8495cf.jpg

These are third-party Team Summit assets, not original project artwork. This repository does not grant a separate license to the images or trademark. The originals are embedded unchanged for offline use.

These two named files are the default branding inputs, separate from controller logic. Replacing them with files of the same formats and rebuilding changes the embedded defaults. Keep assets compact for the ESP32 flash budget.
